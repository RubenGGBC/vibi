# Caras de herramientas de Vibi

Checklist de las familias funcionales que devuelve `frontend/src/lib/faceTool.ts`.
Una casilla marcada significa que la transformacion completa esta aprobada y
aplicada al companion y a la app core local. Los mocks no se marcan hasta recibir aprobacion.

- [x] `working` - Herramienta generica o no reconocida. Vibi se convierte en un mecanismo universal.
- [x] `searching` - Busqueda en internet (`search_web`, `web_search`, `websearch`). Vibi se convierte en una lupa.
- [x] `hacking` - Terminal y comandos (`terminal`, `shell`, `bash`, `run_command`, `execute`). Vibi se convierte en el terminal.
- [x] `browsing` - Paginas y navegador (`webfetch`, `read_url`, `browser_`, `playwright`). Vibi se convierte en el navegador.
- [x] `rummaging` - Carpetas y busqueda de archivos (`list_directory`, `files_search`, `glob`, `grep`). Vibi se convierte en una carpeta.
- [x] `reading` - Lectura de archivos (`read_file`, `view_file`, `read`). Vibi se convierte en un libro.
- [x] `writing` - Escritura y edicion (`write`, `edit`, `replace`). Vibi se convierte en una pluma.
- [x] `noting` - Creacion de notas (`create_note`). Vibi se convierte en una nota.
- [x] `peeking` - Captura o inspeccion de pantalla (`screenshot`, `ui_snapshot`). Vibi se convierte en una camara.
- [x] `handling` - Manejo de pantalla (`ui_batch`, `click`, `scroll`, `keyboard`). Vibi se convierte en un raton.
- [x] `launching` - Apertura de aplicaciones, direcciones y rutas (`launch_app`, `open_url`, `open_path`). Vibi se convierte en un cohete.
- [x] `sending` - Movimiento o envio de archivos (`send_file`). Vibi se convierte en un sobre.
- [x] `reaching` - Acceso a otro equipo (`devices`, `pc_`). Vibi se convierte en una antena.
- [x] `vibing` - Musica y contenido multimedia (`media`, `youtube`). Vibi se convierte en un altavoz.
- [x] `forjando` - Creacion y prueba de una herramienta nueva (`forjar`). Vibi se convierte en una forja.
- [x] `trastienda` - Trabajo en el escritorio de fondo (`trastienda`). Vibi se convierte en una capsula-taller.
